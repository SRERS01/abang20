If the endpoint register/?password=${...} is vulnerable to Client-Side Template Injection (CSTI), an attacker can replace the harmless alert(1) testing string with automated scripts designed to harvest new user credentials as they register. When an application falls victim to a template breakout, the injected code runs with the exact same security permissions as the website itself.
