With AP isolation disabled on your router, devices on your local network can communicate freely with one another. From your Ubuntu terminal or desktop, you can interact with these devices using several built-in tools and protocols, categorized by what you want to do. [1] (https://www.tp-link.com/us/blog/2586/what-is-ap-isolation-and-when-to-enable-it-/)

1. Network Discovery & Scanning

Before interacting with a device, you usually need to find its local IP address or open services.
• Ping Sweep (nmap). Install Nmap (sudo apt install nmap) and run nmap -sn 192.168.1.0/24 (adjust to your subnet) to list all active devices and their MAC addresses on the network.
• Port & Service Scanning (nmap). Run nmap -sV <target-ip> to see which ports are open and what software/services a specific device is running.
• ARP Cache Inspection (ip neigh). Run ip neigh or arp -a to view devices your Ubuntu machine has recently communicated with on the local link.
• mDNS / Avahi Discovery (avahi-browse). Run avahi-browse -rt _workstation._tcp (or -a for all services) to discover Apple devices, printers, smart home gear, and Linux machines broadcasting .local hostnames. [1] (https://www.youtube.com/watch?v=GzP8uhrD_Qs)

2. Remote Shell & Command Execution

If the target devices are other Linux machines, macOS systems, Raspberry Pis, or modern Windows setups:
• SSH (ssh). Connect to a remote terminal using ssh user@<target-ip>. You can also forward GUI apps over SSH using ssh -X user@<target-ip>.
• Telnet / Netcat (telnet / nc). Useful for interacting with raw TCP/UDP sockets, legacy routers, or IoT microcontrollers via nc <target-ip> <port>. [1] (https://unix.stackexchange.com/questions/793503/connecting-directly-two-devices-connected-to-internet)

3. File Transfer & Network Shares

You can push, pull, or mount files directly across devices on your LAN.
• SCP & SFTP (scp / sftp). Securely copy files over SSH without extra setup: scp file.txt user@<target-ip>:/path/to/destination.
• Rsync (rsync). Fast, incremental file synchronization over SSH: rsync -avz /local/dir/ user@<target-ip>:/remote/dir/.
• Samba / SMB (smbclient or File Manager). Access Windows shared folders or NAS drives. Open Ubuntu's default file manager, press Ctrl + L, and type smb://<target-ip>/sharename.
• NFS (mount -t nfs). Mount Linux-to-Linux network drives directly into your Ubuntu filesystem.
• Quick Ad-Hoc HTTP Server (python3). Run python3 -m http.server 8000 in any Ubuntu folder to let any device on the network download files via a web browser at http://<ubuntu-ip>:8000.
• LocalSend or KDE Connect. Cross-platform apps for drag-and-drop file sharing, clipboard sync, and notifications with phones and desktops on the same Wi-Fi.

4. Screen Sharing & Remote Desktop

• VNC (remmina or vinagre). Use Ubuntu's built-in Remmina client to connect to VNC servers running on macOS, Raspberry Pi, or other Linux desktops.
• RDP (remmina or xfreerdp). Connect to Windows Pro/Enterprise desktops using Remote Desktop Protocol via Remmina.
• ADB (adb). If you enable Wireless Debugging on an Android phone or TV on the same network, run adb connect <phone-ip>:<port> from Ubuntu to control the screen, push APKs, or run shell commands.

5. Web Interfaces, Media & IoT Casting

• Local Web Dashboards. Many routers, printers, cameras, and smart home hubs host web interfaces you can access directly in Firefox or Chrome by navigating to http://<device-ip>.
• UPnP / DLNA Streaming. Use VLC or Rygel on Ubuntu to stream local video and audio directly to Smart TVs and media players on the network.
• Network Printing (CUPS). Open http://localhost:631 or Ubuntu's Settings > Printers to automatically discover and print to Wi-Fi printers over IPP.

6. Mesh & Overlay Networking (Optional)

• Tailscale or ZeroTier. Even on a local network, one point of agreement among users on Reddit is that tools like Tailscale simplify peer-to-peer connections, MagicDNS naming, and file drops (tailscale file cp) without needing to track changing DHCP IP addresses.
