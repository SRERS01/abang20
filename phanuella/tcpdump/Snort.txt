Snort is an important addition, but it performs a different job from tcpdump, Wireshark and TShark.

Snort is a Network Intrusion Detection and Prevention System (NIDS/NIPS). Its primary purpose is to monitor network traffic, inspect packets against security rules, and identify suspicious or malicious activity.

Think of the four tools this way:

* tcpdump: Collects network packets.

* Wireshark: Helps you investigate packets visually.

* TShark: Automates packet dissection and extraction.

* Snort: Detects suspicious network activity using security rules.

### What Snort can do

* Detect suspicious network connections.

* Detect port scanning activity.

* Detect known attack patterns.

* Detect suspicious payloads.

* Detect policy violations.

* Detect certain exploit attempts.

* Detect suspicious DNS traffic.

* Detect suspicious HTTP traffic.

* Detect certain brute-force patterns.

* Detect known malware communication patterns.

* Generate security alerts.

* Log suspicious packets.

* Monitor network protocols.

* Apply custom detection rules.

* Integrate threat intelligence rulesets.

* Operate in IDS mode.

* Operate in inline IPS mode when properly configured.

* Help investigate suspicious network activity.

Note: Snort detects patterns covered by its rules. It cannot automatically identify every new vulnerability or attack.

### 4\. Practical Snort commands on Ubuntu

Install:

```bash
sudo apt update
sudo apt install snort -y
```

Check version:

```bash
snort -V
```

List network interfaces:

```bash
ip -br addr
```

Run Snort against an interface (syntax depends on Snort version):

```bash
sudo snort -i eth0 -c /etc/snort/snort.lua
```

Test a PCAP file:

```bash
sudo snort -r capture.pcap -c /etc/snort/snort.lua
```

Check the installed configuration before running these commands; Snort 2 and Snort 3 have different configuration formats and options.
